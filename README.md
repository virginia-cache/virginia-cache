## New to GitHub? Start here

You don't need to know anything about code to use these tools.

### Incident Asset Tracker: download and run

1. Click **⬇ Download** in the table above. A file called `IMT-Asset-Tracker.zip` downloads.
2. Open your **Downloads** folder, right-click the zip file and choose **Extract All…**.
3. Open the **IMT Asset Tracker** folder inside and double-click **`index.html`**. The tracker opens in your browser.
4. Go to **Settings** and type your team name and incident name. You're ready.

Want to try it with sample data? Use **Units → Import roster** and pick `sample-roster-100-units.csv` from the same folder. To load your own units, use **Units → Download roster template**, fill it in with Excel, then **Import roster**.

### "Page not found"?

This tool is in early testing and shared by invitation. If the download link shows **404 / Page not found**:
- make sure you're **signed in** to GitHub (top right of the page), and
- check your email for an invitation from **virginia-cache** and click **Accept**.
