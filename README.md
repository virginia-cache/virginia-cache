# Virginia Cache

Free, no-install tools for emergency communications and incident management.
Each one runs in **Microsoft Edge or Google Chrome**. There is nothing to install and no account to create.

Pick the tool you want:

| | Tool | What it's for | Start here |
|---|---|---|---|
| 🗺️ | **[Incident Asset Tracker](https://github.com/virginia-cache/imt-asset-tracker)** | A unit-and-call board for Incident Management Teams, TERT deployments, or a 911 center whose CAD is down. Track units and calls, check addresses on a map, and share one board across up to 10 laptops. | **[⬇ Download](https://github.com/virginia-cache/imt-asset-tracker/archive/refs/heads/main.zip)** · [How to use it](https://github.com/virginia-cache/imt-asset-tracker#readme) |

## New to GitHub? Start here

You don't need to know anything about code to use these tools.

### Incident Asset Tracker: download and run

1. Click **⬇ Download** in the table above. A file called `imt-asset-tracker-main.zip` downloads.
2. Open your **Downloads** folder, right-click the zip file and choose **Extract All…**.
3. Open the extracted folder and double-click **`index.html`**. The tracker opens in your browser.
4. Go to **Settings** and type your team name and incident name. You're ready.

To load a list of units, use **Units → Download roster template**, fill it in with Excel, then **Import roster**.

### DSD-Web: open and connect

1. Click **▶ Open it** in the table above. The page opens in your browser.
2. Plug in your RTL-SDR dongle and press **Connect & start**.
3. Windows only: the dongle needs a one-time driver change first. The [DSD-Web instructions](https://github.com/virginia-cache/dsd-web#readme) explain it step by step.

### "Page not found"?

These tools are in early testing and shared by invitation. If a link shows **404 / Page not found**:
- make sure you're **signed in** to GitHub (top right of the page), and
- check your email for an invitation from **virginia-cache** and click **Accept**.
